# 한눈에 버스길

공공데이터로 버스정류장과 주변 시설을 연결하고, 운행 방향에 맞는 하차 후보를 보여주는 정류장 키오스크 시제품입니다. 작성자: 유지우.

기준 정류장은 성남역.이매고교.아름마을.효성선경아파트 **07159**이며, 반대편 **07303**도 확인할 수 있습니다. 대상 노선은 **55·351·422·9407·누리4·3-1**입니다.

## 분석 기준과 결과

- 버스 자료: 2026-10-16 수집. 시설 자료: 2026-10-11 보존분에서 노선 주변 부분집합 추출.
- 정류장과 시설 대표점 사이 **직선 반경 500m**를 사용했습니다. 200m·300m 결과도 비교합니다.
- 명칭에 `(경유)`·`(미정차)`가 있는 방문 기록은 승하차 후보에서 제외합니다. 원본 순서와 노선 형상은 유지합니다.
- 승하차 후보 방문 536개, 고유 시설 후보 329곳, 표시 대상 고유 시설 309곳입니다. 방문 기록 수는 고유 정류장 수와 다릅니다.
- 표시 시설의 명칭 대응: 전체 이름 명시 40곳, 약칭·생략 검토 18곳, 규칙상 대응 미확인 251곳입니다.
- 각 방향의 노선×시설 498조합 중 현재 구간에 대안이 있지만 거리만 선택하면 구간 밖 후보를 고르는 경우는 07159에서 93건, 07303에서 128건입니다.

위 수치는 문자 비교와 가상 선택 규칙의 계산 결과입니다. **이용자 오류율, 상용 지도 오류율, 고령층 사용성 개선 효과가 아닙니다.** 시설 입구·횡단 안전·실제 보행거리·도착 예정시간은 검증하지 않았습니다.

## 실행환경

검증 환경: Windows, Python 3.13.3, Node.js 24.16.0. Python과 Node.js는 각각 설치해야 합니다. npm 패키지는 사용하지 않습니다.

```powershell
git clone https://github.com/jiwordan/bus-landmark-kiosk.git
cd bus-landmark-kiosk
python -m pip install -r requirements.txt
```

Pillow는 분석 그래프 생성과 관련 테스트에 사용합니다. 수치 집계와 로컬 서버는 Python·Node.js 기본 라이브러리로 실행합니다.

## 인증키 없이 분석 재현

저장된 CSV를 읽는 명령으로, 외부 API를 호출하지 않습니다.

```powershell
node scripts/build_report_evidence.mjs
```

결과: `data/processed/imae-kiosk/report-2026-10-18/analysis.json`. 위의 309·40·18·251·93·128 수치를 확인할 수 있습니다. 동일 경로의 기존 집계 파일을 다시 생성하므로 비교용 원본이 필요하면 먼저 복사해 두세요.

독립적인 CSV·해시 검증 및 기능 테스트:

```powershell
$env:PYTHONUTF8 = '1'
python -X utf8 -m unittest discover -s tests -p 'test_*.py' -q
node --test tests/map-state.test.mjs tests/kiosk-flow.test.mjs tests/kiosk-evidence.test.mjs tests/report-evidence.test.mjs
```

이 저장소의 Python 테스트는 최신 자료 재현과 수집·거리·지도·차량 처리 검사를 선별한 것입니다. Node 테스트의 지도 SDK는 테스트용 대체 구현이며 실제 네이버 지도 화면 검증을 대신하지 않습니다. 테스트는 실제 키를 사용하지 않습니다.

## 지도 시제품 실행

```powershell
Copy-Item .env.example .env.local
```

`.env.local`에 **본인 계정의** 설정을 입력합니다.

- `NAVER_MAPS_CLIENT_ID`: 네이버 클라우드의 Maps > Dynamic Map Client ID. Client Secret이 아닙니다. Web 서비스 URL에 `http://localhost:8080`을 등록합니다.
- `DATA_GO_KR_SERVICE_KEY`: 경기도 버스위치정보 조회 활용신청 후 받은 공공데이터포털 인증키입니다. 실시간 차량 조회에만 필요합니다.

```powershell
python -X utf8 -m scripts.map_server
```

브라우저에서 `http://localhost:8080/`을 엽니다. 이 서버는 로컬 접속만 허용합니다. 네이버 키가 없으면 배경지도를 열 수 없지만 위 수치 분석은 재현할 수 있습니다. 버스 위치 키가 없으면 차량 조회만 실패하며 노선 지도는 별개입니다.

시설 선택 시 연결 정류장 이름과 직선거리를 안내합니다. 현재 구간에 후보가 없고 반대편 탑승이 확인될 때 반대 방향 경고를 표시합니다. 차량 표시는 API의 경유 순번을 정류장 좌표에 대응시킨 위치로, 실제 GPS 위치가 아닙니다. 모든 노선이 공유하는 90초 호출 제한을 두었지만 서비스 제공자의 한도·과금 조건은 본인 계정에서 확인해야 합니다.

## 분석 그래프 생성 (Windows)

```powershell
python -X utf8 scripts/build_report_charts.py
```

Windows의 맑은 고딕 글꼴을 사용합니다. 출력은 `docs/submission/2026-10-18-analysis/analysis-charts.png`입니다. 이 경로는 기존 생성 코드의 출력 위치일 뿐이며 옛 보고서 파일은 저장소에 포함하지 않았습니다. 다른 운영체제에서는 이 스크립트의 글꼴 경로를 한글 지원 글꼴로 변경해야 합니다. 글꼴 파일 자체는 배포하지 않습니다.

## 파일 구성과 재수집 범위

- `web/kiosk/`: 지도 화면과 방향별 시설·정류장 선택 로직.
- `scripts/build_report_evidence.mjs`: **최신 309곳 기준 집계 진입점**.
- `scripts/analyze_kiosk_evidence.mjs`: 최신 집계가 재사용하는 명칭·방향 비교 함수. 이 파일을 직접 실행하는 과거 313곳 분석은 이 배포본의 재현 경로가 아닙니다.
- `scripts/landmark_analysis.py`, `collect_imae_routes.py`, `prepare_imae_routes.py`: 거리 계산·수집·전처리 방법을 확인할 수 있는 코드. 수집/전처리 명령은 기존 자료 덮어쓰기를 거부합니다. 전국 시설 원본은 포함하지 않았으므로 이 배포본만으로 원천 수집 전체를 다시 수행할 수는 없습니다.
- `data/processed/imae-kiosk/`: 저장된 노선·시설 부분집합, 검토 상태, 연결표, 최신 집계와 입력 해시. 원래 후보 CSV에는 경유 지점에만 연결된 시설과 보류 시설도 있으며 최신 집계와 앱이 이를 필터링합니다.
- `data/raw/gbis/2026-10-16/imae-kiosk/`: 노선 형상 검증에 사용하는 공식 응답 6개. 요청 URL·인증키는 포함하지 않습니다.
- `tests/`: 실제 외부 API를 호출하지 않는 자동 검사.
- `DATA_SOURCES.md`: 데이터 출처·이용조건 확인 범위와 한계.

신청서·서명·연락처·인증키·브라우저 프로필·지도 타일·지도 캡처·보고서 PDF·옛 문서는 포함하지 않았습니다. 네이버 SDK는 실행 시 공식 서버에서 불러옵니다. 본 저장소 공개가 네이버 지도 이미지나 외부 데이터의 권리를 부여한다는 뜻은 아닙니다.
